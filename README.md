# anigamer-ambilight

繁體中文（本頁）｜[English](README.en.md)

動畫瘋環境光與播放頁主題編輯器。讓影片色彩延伸到頁面四周，也能自行調整配色、透明度、字體與資訊排列。

**受到 [youtube-ambilight](https://github.com/WesselKroos/youtube-ambilight)（WesselKroos）啟發**，並參考 [bilibili-ambilight](https://github.com/iceorange-dev/bilibili-ambilight)。這是非官方工具，保留動畫瘋原播放器與帳號流程。

這個專案是拋磚引玉。我可能不會經常查看 Issue，也不會固定更新，因此回覆或修正可能需要一段時間。歡迎有興趣的朋友 fork、提交修正，或直接大幅改良畫面延伸、效能、手機操作與網站相容性。

## 安裝與更新

[安裝最新版 userscript](https://github.com/Hinataragi/anigamer-ambilight/releases/latest/download/anigamer-ambilight.user.js)

1. 從 [Violentmonkey 官方網站](https://violentmonkey.github.io/) 安裝適用的腳本管理器。
2. 取得本專案提供的 `.user.js` 腳本，在 Violentmonkey 管理頁匯入。若從腳本網址安裝，管理器通常會直接顯示安裝頁。
3. 核對腳本名稱、來源與版本，按「確認安裝」或「確認更新」。
4. 重新整理動畫瘋，按頁首的「觀影設定」。請停用另一份舊腳本或同功能擴充套件，避免重複執行。

也可在 Violentmonkey 管理頁匯入建置出的 `.user.js` 檔案。更新會保留設定；要試新預設，可使用「其他與備份」的全部重設，或按各分類右上角的重設圖示。

更新前建議先匯出設定。請沿用同一份腳本更新，避免同時啟用多個版本；自動更新是否可用，取決於安裝來源與管理器設定。實際版本以腳本開頭的 `@version` 為準。

設定檔的格式版本與腳本版本分開記錄。匯入舊檔時，新選項使用預設值；遇到較新檔案的未知欄位則略過。這能保留已知設定，但不代表舊版能使用新版才有的功能。未來若有不相容的變更，應在更新說明中列出影響與移轉方式。

在「預設主題」開啟「使用自訂色票」，可用選色器或直接輸入十六進位色碼，分別設定背景、面板、按鈕、主要文字、次要文字與重點色。支援 `#112233` 與 `#123`。關閉自訂色票即可回到選定主題。頁尾透出光暈預設開啟，可在「透明度與按鈕」關閉。

完整操作與手機端說明：[安裝教學](docs/INSTALL.md)。

### Chromium 擴充功能

提供 Chrome、Edge 等 Chromium 瀏覽器的手動載入套件。目前暫不考慮上架 Chrome Web Store、Edge Add-ons 或其他瀏覽器商店。

1. 從 [版本下載頁](https://github.com/Hinataragi/anigamer-ambilight/releases/latest) 取得 Chromium 擴充功能 ZIP，解壓縮到固定資料夾。
2. 開啟 `chrome://extensions`。Edge 使用 `edge://extensions`。
3. 開啟「開發人員模式」，選「載入未封裝項目」，指定含有 `manifest.json` 的資料夾。
4. 更新時以新檔覆蓋原資料夾，在擴充功能管理頁按「重新載入」，再重新整理動畫瘋。

### Firefox 擴充功能

Firefox 套件供暫時載入。此套件未經 Mozilla 簽署，一般 Firefox **重新啟動後就會移除**，不是永久安裝版。若希望長期使用，建議採用 Userscript。

1. 從版本下載頁取得 Firefox 擴充功能 ZIP，解壓縮。
2. 開啟 `about:debugging#/runtime/this-firefox`。
3. 選「載入暫時附加元件」，指定解壓縮資料夾中的 `manifest.json`。
4. 重新整理動畫瘋。更新可在同一頁重新載入套件。

三種安裝方式請擇一啟用，避免重複套用樣式與光暈。Chromium 與 Firefox 套件共用功能與原始碼，目前尚未完成各瀏覽器的完整實機測試。

## 三個獨立開關

| 開關       | 用途                         |
| ---------- | ---------------------------- |
| 動態環境光 | 取樣影片，顯示頁面光暈       |
| 主題配色   | 調整頁面顏色、底色與透明度   |
| 版型重排   | 調整資訊排列、間距與收合操作 |

只想用主題，可以關閉動態環境光。只想用光暈，可以關閉主題配色與版型重排。也可保留原站排列，單獨調整字體與底色。

**也可以把它當成普通的動畫瘋美化主題使用。** 關閉「動態環境光」，保留「主題配色」即可調整深淺色、字體與透明度，不需要取樣影片。是否重新排列播放頁面，另由「版型重排」控制。

## 光暈效果

| 延伸方式 | 畫面特色                                         |
| -------- | ------------------------------------------------ |
| 放射投影 | 向四周延伸，作為預設效果                         |
| 圓弧擴散 | 柔化四角，減少方框感                             |
| 輪廓延展 | 延續外框色彩                                     |
| 柔光擴散 | 模糊細節，保留色彩                               |
| 邊緣反射 | 鏡像延伸，保留更多細節                           |
| 邊緣光帶 | 只顯示外框色彩                                   |
| 邊緣拉伸 | 使用原畫面像素做偽延伸，人物、建築與文字可能變形 |
| 旋流延伸 | 向外延伸時逐漸旋轉，可調整旋轉幅度               |

這些效果不是 AI 畫面補全，不會生成影片之外的場景。各方法有自己的形狀設定，也能調整亮度、範圍、模糊、細節、色彩濃度與對比。

「快速套用」提供自然延伸、清晰畫面、柔和色彩、淡色光暈。它們只改光暈效果；畫質與更新方式在另一個分類調整。

## 主題與頁面操作

- 六種預設主題：沉浸墨藍、低彩石墨、暖紙淺色、森林夜色、暮紫、清楚閱讀。
- 深色、淺色或跟隨系統，可自訂重點色、字級、行距、圓角與區塊間距。
- 頁首、彈幕列表、作品資訊、相關動畫、新聞與留言，可分別調整背景不透明度。
- 按鈕與搜尋欄可選主題底色、透明底色或原站配色。
- 集數、作品資訊、相關動畫、新聞與留言預設展開，附收合按鈕。集數也可換行或單列捲動。
- 「專注觀看」收起周邊資訊；「收合彈幕」可單獨隱藏旁邊的列表，再按一次即可恢復。
- 彈幕列表可隱藏捲軸，仍能捲動。留言區可調寬度、密度與圖片大小。
- 播放器預設沿用原站自適應，自訂劇院最大寬度須另外啟用。
- 可隱藏右側頁面展示廣告，保留影片廣告；影片廣告期間暫停取樣。

## 字體

內建系統字體、Noto Sans TC、Noto Serif TC、芫荽、霞鶩文楷 TC、昭源黑體及昭源宋體。

Google 字體只在選用時載入。選「自訂字體」可輸入 Google Fonts 的字體家族名稱，或停用網路載入、改用裝置已安裝的字體；輸入後離開欄位即可套用。

套用範圍包含導覽、標題、資訊、新聞、留言、彈幕列表與設定面板，保留圖示字型。可另啟用播放器彈幕字體，但只對 DOM 文字有效；Canvas 彈幕及影片內建字幕無法用頁面 CSS 更換。

## 設定分類

| 分類         | 可調內容                               |
| ------------ | -------------------------------------- |
| 預設主題     | 六種配色與重點色                       |
| 光暈效果     | 快速套用、延伸方式與畫面細節           |
| 外觀與字體   | 深淺色、字體、閱讀大小與設定面板透明度 |
| 透明度與按鈕 | 各區背景與控制項底色                   |
| 版面與間距   | 區塊重排、播放器布局與間距             |
| 顯示與收合   | 顯示資訊、收合操作與彈幕列表           |
| 流暢度與畫質 | 光暈解析度、更新方式與渲染狀態         |
| 影片黑條     | 取樣裁切與可選黑條覆蓋                 |
| 其他與備份   | 頁面廣告、設定匯入、匯出與全部重設     |

設定會自動儲存。單項與分類重設皆使用圖示；鍵盤聚焦或滑鼠停留時可辨識用途。桌面設定面板置中放大，手機與平板使用較窄的面板。

## 預設效能與限制

預設從 960 px 光暈解析度開始，跟隨影片新影格更新，不把 24 fps 動畫重畫成 60 fps。畫面平滑預設為 0，避免混合舊幀造成拖影；自動畫質會在負載高時減少像素量。

參考 youtube-ambilight 的影片影格回呼同步、GPU 紋理重用與停畫條件。WebGL 2 不可用時退回 Canvas；GPU 計時不可用時使用提交耗時與漏幀訊號。硬體加速由瀏覽器、驅動及系統決定，腳本無法強制啟用。

黑條覆蓋預設關閉，需自行啟用。偵測到字幕、圖案或暗場不確定時會保留原畫面，仍可能漏掉很小或很暗的文字。部分 DRM 或跨來源影片不允許取樣，此時保留原播放器。

自動測試包含設定操作、黑條辨識與 GPU API 呼叫。

## 瀏覽器與隱私

Chrome、Edge、Firefox 與 Safari 的 API 差異已有備援，尚未完成各瀏覽器實播驗證。手機與平板須使用支援 userscript 的瀏覽器或管理工具。

設定由腳本管理器或瀏覽器儲存，擴充功能可能依瀏覽器設定同步到帳號。選用網路字體時會向 Google Fonts 請求字型，詳見 [隱私政策](docs/PRIVACY.md)。不讀取動畫瘋帳號密碼，也不接管登入流程。

## 開發與建置

原始碼拆分維護，安裝時使用建置產生的單檔 userscript。需要 Node.js 與 npm。

```sh
npm ci
npm test
npm run build
```

```text
anigamer-ambilight/
├── src/                    設定、渲染器、黑條偵測、網站適配與樣式
├── scripts/build.mjs       建置單檔 userscript 與擴充套件
├── tests/                  設定、黑條與 GPU API 測試
├── docs/                   安裝與隱私說明
├── package.json
├── package-lock.json
├── LICENSE
├── LICENSE.youtube-ambilight
└── LICENSE.bilibili-ambilight
```

產物為 `dist/ani-ambilight.user.js`、`dist/extension/`（Chromium）與 `dist/extension-firefox/`（Firefox）。`node_modules/`、`dist/` 和 ZIP 不納入版本控制。userscript 保留可讀排版與繁體中文分區註解；Prettier 只在建置時執行。

GitHub Actions 在提交與 Pull Request 時執行測試和建置。推送與專案版本一致的 `v*.*.*` 標籤時，自動產生三種安裝套件並建立 GitHub Release。
