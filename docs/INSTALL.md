# 安裝與使用

## Violentmonkey userscript（建議）

1. 從 [Violentmonkey 官方網站](https://violentmonkey.github.io/) 選擇您使用的瀏覽器，安裝腳本管理器。
2. 在裝有管理器的瀏覽器點擊 [GitHub 最新版安裝連結](https://github.com/Hinataragi/anigamer-ambilight/releases/latest/download/anigamer-ambilight.user.js)，或到 [Greasy Fork](https://greasyfork.org/zh-TW/scripts/598131-anigamer-ambilight) 按「安裝此腳本」。
3. Violentmonkey 會顯示腳本名稱、程式碼與權限。確認名稱為「anigamer-ambilight｜動畫瘋環境光與沉浸版面」，再按「確認安裝」。
4. 重新整理動畫瘋。既有登入狀態仍由動畫瘋與原瀏覽器管理。
5. 頁首右側按「觀影設定」，分別開關光暈、主題配色、版型重排。

若瀏覽器直接下載檔案，請在 Violentmonkey 管理頁使用「從檔案匯入」。請保留同一份腳本更新，避免重複啟用。

GitHub 連結固定指向最新 Release，不需要自行尋找版本。Greasy Fork 安裝版由 Greasy Fork 提供更新，GitHub 安裝版則從 GitHub 檢查更新。

### 離線檔案

也可在 Violentmonkey 管理頁使用「從檔案匯入」，選擇下載的 `.user.js` 檔案；或新增腳本，把完整檔案貼入編輯器後儲存。請只保留一份動畫瘋環境光，避免同時執行舊擴充功能與 userscript。

## 怎麼調整

- **設定分類**：首頁分成「預設主題」「光暈效果」「外觀與字體」「透明度與按鈕」「版面與間距」「顯示與收合」「流暢度與畫質」「影片黑條」「其他與備份」。進入分類才顯示設定。按「所有設定」回到分類總覽，Esc 先返回，再按一次關閉。
- **預設主題**：沉浸墨藍、低彩石墨、暖紙淺色、森林夜色、暮紫、清楚閱讀。主題套用配色、字級與遮光，不改動播放版型、光暈或效能設定。
- **版面與間距**：各區塊可分別決定是否重排，也可調整圓角與間距。播放器預設沿用原站自適應；勾選自訂劇院最大寬度後，寬度滑桿才可操作。
- **顯示與收合**：可分別顯示彈幕列表、作品資訊、相關動畫、新聞及留言；集數可選換行、單列捲動或收合；作品資訊、相關動畫、新聞、留言也可各自開啟收合。留言密度、圖片大小與彈幕列表文字另有設定。
- **系統字體 / Google Fonts**：在「外觀與字體」切換黑體、宋體或芫荽，預覽下方會顯示載入狀態。套用導覽、標題、資訊、彈幕列表、新聞與留言；不取代播放器圖示或影片本身字幕。字體選擇不依賴重新設計開關；系統字體不另外下載字型。
- **延展方法**：在「光暈效果」選擇放射投影（向四周展開）、圓弧擴散（柔化四角）、輪廓延展（延續邊緣色彩梯度）、柔光擴散（降低背景細節）、邊緣反射（保留更多畫面細節）、邊緣光帶（不複製畫面）、邊緣拉伸（非 AI 偽延伸）或旋流延伸（向外旋轉）。這些方法都不會生成影片外的場景。
- **快速套用**：「自然延伸」適合一般觀看；「清晰畫面」保留更多細節；「柔和色彩」增加模糊；「淡色光暈」降低細節。這些組合只改效果；解析度與更新方式請到「流暢度與畫質」選擇。
- **亮度 / 延伸範圍 / 模糊程度**：分別影響背景光量、覆蓋範圍和邊緣細節。
- **畫面混合**：預設為 0，避免追色延遲；調高會減少跳動，同時增加殘影。
- **頁面遮光**：數值越高越不透明。頁首、彈幕列表、作品資訊、相關動畫、新聞、留言可分別調整。
- **版型重排**：關閉後保留動畫瘋原排版，仍可單獨使用光暈與介面配色。
- **右側頁面廣告**：可隱藏展示廣告；不跳過、不攔截影片廣告。
- **影片黑條覆蓋**：預設關閉。在「影片黑條」開啟「用光暈覆蓋影片黑條」。可辨識上下、左右、四周留黑；連續確認後才遮去黑條並露出光暈，影片內容比例保持不變。暗場或辨識不確定時會保留原畫面；影片廣告和全螢幕時還原。自動取樣裁切與實際黑條覆蓋是不同選項。
- **渲染狀態**：「流暢度與畫質」顯示 WebGL / Canvas、加速狀態、實際畫布寬度與提交耗時。提交耗時不是螢幕端完整延遲。WebGL 2 優先請求高效能 GPU；硬體加速仍由瀏覽器、驅動與裝置設定決定。若瀏覽器隱藏 GPU 資訊會顯示「加速狀態未公開」，不冒稱已驗證。

### 更新與備份

沿用同一份腳本更新，版本以檔案開頭的 `@version` 為準。更新保留設定，建議事先匯出 JSON 備份。若要使用預設值，可重設單項、整個分類或全部設定。

## 停用與還原

在 Violentmonkey 選單關閉此腳本，再重新整理動畫瘋，即回到原站介面。只關閉「版型重排」可保留光暈與配色。設定面板的「還原預設」會還原本工具設定，不改動畫瘋帳號或播放器偏好。

## 遇到問題

- **沒有生效**：確認腳本已啟用、網址為 `https://ani.gamer.com.tw/`，再重新整理。
- **有兩個設定按鈕 / 重複光暈**：停用另一份舊腳本或舊擴充功能。
- **光暈跟不上**：在「流暢度與畫質」選「流暢優先」，並把畫面平滑設為 0；提高更新率不會增加影片本身的影格數。
- **淺色 / 深色**：頁面設定可切換外觀。預設遮光以可閱讀為目標；手動降到極低透明度可能降低對比。
- **無法讀取影片畫面**：部分 DRM 或跨來源影片不允許取樣，此時原播放器仍可使用。

## Chrome 的腳本執行權限

不同版本的 Chrome 與腳本管理器可能需要額外開啟 userscript 執行權限。請依已安裝管理器的提示操作；例如 Tampermonkey 官方說明指出 Chrome 138+ 可在擴充功能詳細資料開啟「允許使用者指令碼」。詳見 [官方說明](https://www.tampermonkey.net/faq.php?q=Q209)。

## 配色與版型

「主題配色」只調整顏色與遮光；「版型重排」調整排列。兩者可分別開關。每項設定旁的重設圖示只重設該項；「其他與備份」的「還原預設」會重設全部設定。舊設定會保留，更新不會自動把你調過的數值改掉。

頁首與彈幕列表的遮光、場景色預設都是 0%。強烈戰鬥特效若讓眼睛疲勞，可選「柔和光暈」並降低亮度；也可提高彈幕列表遮光，保留閱讀對比。

## 光暈畫質與黑條

1. 到「流暢度與畫質」選「流暢優先」：背景解析度 960 px、跟隨影片影格更新、畫面混合 0。舊設定會保留，更新本身不會覆蓋您的效能選擇。
2. 要移除影片內黑條，請到「影片黑條」開啟「用光暈覆蓋影片黑條」。只開「偵測黑條並避開取樣」不會隱藏黑條。偵測到亮色字幕或圖案時，會保留原畫面；取樣仍可能漏掉很小或很暗的文字。

光暈提供八種方法。選擇方法後，其專屬形狀設定會顯示在方法下方，其餘方法的形狀設定會收起。邊緣拉伸用原畫面像素做偽延伸，沒有 AI 推論；人物、建築和文字可能變形。Canvas 相容模式的效果較簡化。

自動畫質預設開啟。「流暢優先」從 960 px 開始，最低 640 px；「清晰優先」從 1600 px 開始，最低 960 px；「省電」為 640 px／30 fps，最低 480 px。下限不超過實際視窗或設定寬度。可關閉自動畫質固定解析度。支援時會以非阻塞 GPU 計時輔助判斷負載；不支援時使用提交耗時和漏幀訊號。

### 瀏覽器相容性

預設跟隨影片的新影格更新，不會把 24 fps 動畫重畫成 60 fps。支援 `requestVideoFrameCallback` 時使用影片回呼；其餘情況使用畫面回呼與可取得的解碼影格計數，避免重複繪製。WebGL 2 無法使用時退回 Canvas；GPU 計時擴充缺少時仍可自動調整畫質。硬體加速是否可用由瀏覽器、驅動與系統設定決定，腳本無法強制開啟。

Chrome、Edge、Firefox 與 Safari 的 API 差異已有備援，但目前並未完成這些瀏覽器的暴力猴實播測試。Safari 需另用支援的 userscript 管理工具；手機端也依瀏覽器與管理工具而異。
