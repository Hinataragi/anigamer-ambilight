# 隱私政策

繁體中文｜[English](PRIVACY.en.md)

更新日期：2026 年 10 月 1 日。適用於本專案的 Userscript、Chromium 與 Firefox 擴充功能。

## 執行範圍

這是非官方工具，網站腳本只在 `https://ani.gamer.com.tw/*` 執行。擴充功能只要求設定儲存權限，沒有要求讀取瀏覽紀錄、帳號密碼或其他網站的權限。不接管動畫瘋登入流程，不攔截影片廣告，也不繞過 DRM 或訂閱限制。

## 影片與頁面資料

影片取樣、黑條辨識與光暈渲染都在瀏覽器內進行。取樣畫面用於當次渲染，不建立影片紀錄或上傳影像。本專案沒有資料收集伺服器、分析追蹤或遙測端點。

程式會讀取播放頁的元素與播放器狀態，以套用樣式、顯示收合控制及判斷何時更新光暈。這些操作不會將帳號、留言、彈幕或觀看紀錄傳送給專案作者。

## 設定儲存

儲存內容是使用者選擇的配色、字體、光暈、版型與其他功能設定。

- Userscript 使用腳本管理器的儲存空間。是否備份或同步到雲端，由管理器及使用者設定決定。
- 擴充功能使用瀏覽器的 `storage.sync`。若瀏覽器帳號啟用同步，設定可能由瀏覽器廠商的同步服務儲存。
- 本專案不另行將設定傳送給作者，也不儲存動畫瘋密碼或登入憑證。

## 外部連線

預設使用系統字體。選用 Google Fonts 或開啟自訂字體的 Google 載入選項時，瀏覽器會連接 `fonts.googleapis.com` 與 `fonts.gstatic.com` 下載樣式及字型。Google 會收到下載所需的一般連線資訊，例如 IP 位址與瀏覽器提供的請求資訊，處理方式以 [Google 的隱私政策](https://policies.google.com/privacy) 為準。

切回系統字體，或關閉自訂字體的網路載入，可停止本工具新增的字型請求。已下載的字型可能保留在瀏覽器快取。動畫瘋本身載入的字型及其他連線不由本工具管理。

從 GitHub 安裝的 Userscript 包含更新網址。腳本管理器可能依設定向 GitHub 檢查或下載更新。若從其他平台安裝，更新連線依該平台與管理器的處理方式而定。手動載入的擴充功能沒有設定遠端自動更新服務。

## 匯出、匯入與移除

匯出功能將設定下載為 JSON 檔案，不自動上傳。匯入功能在瀏覽器內解析檔案，驗證已知欄位並略過未知欄位。自訂字體名稱等內容會包含在備份中，分享前請自行檢查。

「還原預設」會把功能設定改回預設值，不等於刪除管理器或瀏覽器的儲存空間。若要移除儲存資料，請使用腳本管理器的資料清除或刪除功能，或移除擴充功能並依瀏覽器說明清除資料。瀏覽器同步及備份中的副本須另依該服務設定處理。停用工具並重新整理頁面即可停止套用。

## 政策更新與聯絡

新增外部連線、儲存項目或資料處理方式時，應同步更新這份政策並在版本說明中交代變更。政策不涵蓋動畫瘋、瀏覽器、腳本管理器或第三方下載平台本身的資料處理。

如有隱私疑問，可透過 [GitHub Issues](https://github.com/Hinataragi/anigamer-ambilight/issues) 聯絡。請勿公開張貼帳號憑證或其他敏感資料。作者可能不會經常查看 Issue，無法保證即時回覆。
